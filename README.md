# Coxy Wallet

<img alt="image" src="https://github.com/user-attachments/assets/b85e28c5-4c46-43ea-a9f1-2e4cbb38815f" />


This is a Cardano, Midnight, Bitcoin, Ethereum, Solana, XRP, Doge, Ethereum Classic and Binance Easy to Use, Secure Multichain Self-Hosted and Cross Platform Wallet.  

One of the biggest blockchain headaches are wallets. They are not secure, not user friendly, not cross platform, difficult to learn, for any transaction a user has to run around looking for transaction fees, and above all do not compete is usability to web2 applications. I know this from over 3 years training blockchain especially Cardano to tertiary students. This aims to change all this.

Research says: "A next-generation multichain wallet should make secure asset management, payments, application connectivity, recovery, governance, and digital identity easier to understand and use. This report synthesizes current adoption estimates, wallet-security literature, relevant technical standards, and practical product-design principles. It distinguishes user needs supported by external research from proposed product hypotheses that require testing. The resulting architecture places local key protection, explicit authorization, verifiable transaction outcomes, network-specific capabilities, and trustworthy recovery ahead of more speculative features. Artificial intelligence, advanced DeFi services, programmable assets, digital credentials, and privacy controls remain valuable optional layers, but they must not weaken the security of everyday transactions.".
